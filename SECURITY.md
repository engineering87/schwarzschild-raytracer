# Security policy

## Scope

This project is a static HTML page and a pair of offline Python scripts. It
sends no network requests at runtime other than an optional web font, stores no
user data, and requires no server side component. The attack surface is
correspondingly small.

## Reporting a vulnerability

If you find a security issue, please open a private security advisory through
the GitHub Security tab of this repository rather than a public issue. Include
the affected file, the browser or Python version, and a reproduction if you
have one. You can expect an acknowledgement within seven days.

## Out of scope

Reports about the physics being an approximation of reality are not security
issues. They are welcome as ordinary issues, and the known approximations are
already documented in `docs/PHYSICS.md`.
